# GOS//SIM

Интерактивная учебная платформа для моделирования политико-административного / государственного управления.

## Быстро посмотреть

Откройте `demo/index.html`. Для записи аудио/видео лучше запустить локальный сервер:

```bash
cd demo
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

**Демо-преподаватель:** код `PREPOD2026`.

## Что уже есть в демо

- вход по ФИО и коду игры;
- отдельный режим преподавателя;
- адаптивный интерфейс;
- раунд и таймер;
- показатели государства;
- лента событий;
- карта напряжения;
- персональные задачи;
- конструктор действий студента;
- очередь и оценка действий преподавателем;
- следующий раунд / пауза / открытие хода;
- публикация новых событий;
- общий чат;
- запись аудио/видео через MediaRecorder;
- отправка файлов (демонстрационно);
- документы и институты;
- аналитика;
- журнал аудита и экспорт JSON;
- сохранение основной демо-сессии в localStorage.

## Production backend

`supabase/schema.sql` содержит полноценную PostgreSQL-схему, RLS, Realtime-таблицы, приватный Storage bucket для медиа, join-code RPC, аудит и роли.

## Документация

- `docs/ARCHITECTURE.md` — полная концепция продукта.
- `docs/RULES_ADAPTER.md` — как перенести точные правила исходной игры.

## Важно

Демо — работающий интерактивный прототип, но не многопользовательский сервер. Production-схема подготовлена для реального backend, однако для запуска в интернете ещё нужно подключить проект Supabase, переменные окружения и frontend-клиент к таблицам/RPC.
