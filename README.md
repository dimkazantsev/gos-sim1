# GOS//SIMS

Интерактивная учебная платформа для моделирования политико-административного / государственного управления.

## Быстро посмотреть

Откройте `demo/index.html`. Для записи аудио/видео лучше запустить локальный сервер:

```bash
cd demo
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

**Демо-преподаватель:** код `PREPOD2026`.

## Что уже есть в демо

- вход по ФИО и коду игры;
- отдельный режим преподавателя;
- адаптивный интерфейс;
- раунд и таймер;
- показатели государства;
- лента событий;
- карта напряжения;
- персональные задачи;
- конструктор действий студента;
- очередь и оценка действий преподавателем;
- следующий раунд / пауза / открытие хода;
- публикация новых событий;
- общий чат;
- запись аудио/видео через MediaRecorder;
- отправка файлов (демонстрационно);
- документы и институты;
- аналитика;
- журнал аудита и экспорт JSON;
- сохранение основной демо-сессии в localStorage.

## Production

Основное приложение работает на Next.js 16 + Supabase и разворачивается через Vercel. Production-база включает PostgreSQL/RLS, Realtime, Storage, игровые RPC, аудит, формальные институты, политические процессы и автоматический журнал ВСН по всем 16 этапам.

Журнал ВСН ведёт черновые оценки 0–3, пересчитывает их каждый час и дополнительно в локальное 03:00, сохраняет историю пересчётов и доказательства действий студента. Итоговый балл фиксирует преподаватель; прямое изменение таблиц оценивания со стороны клиента запрещено.
