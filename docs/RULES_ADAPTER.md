# Адаптер правил исходной игры

Исходный Google Docs по ссылке из запроса был доступен веб-инструменту только как оболочка документа: он подтвердил название «Моделирование ПАУ/ГПУ», но не отдал текст правил. Поэтому текущая версия проекта намеренно построена как универсальный движок, куда правила можно загрузить конфигурацией, не переписывая интерфейс.

Для точной интеграции исходной игры потребуется перенести из документа в конфигурацию следующие сущности:

1. роли и количество игроков на каждую роль;
2. полномочия каждой роли;
3. этапы/раунды;
4. обязательные документы и действия;
5. порядок согласования и принятия решения;
6. ресурсы и ограничения;
7. события/кризисы;
8. правила начисления баллов;
9. условия завершения игры;
10. видимость информации для разных ролей.

В БД для этого уже предусмотрены `games.settings`, `institutions`, `missions`, `game_documents`, `rounds`, `state_metrics`, `regions`, `game_events` и `player_actions.payload`.
