# ГОС.ID — связь безопасности с действующими системами

Утверждено 23.11.2026. Государственные программы не участвуют.

## Новые коэффициенты

| Подтверждённый источник | Эффект безопасности, п.п. |
| --- | ---: |
| Инфляция +1 п.п. | −0,8 |
| Ключевая ставка +1 п.п. | −0,5 |
| Деловая активность, самостоятельная ручная настройка +1 п.п. | +0,6 |
| Экономика +1 п.п. | +0,7 |
| Социальное напряжение +1 п.п. | −0,4 |
| Правовая устойчивость +1 п.п. | +0,3 |
| Международное положение +1 п.п. | +0,2 |
| Подтверждённое изменение кризиса | −0,10 × изменение угрозы + 0,05 × изменение локализации |
| Подтверждённое завершение кризиса | +1 однократно |
| Ситуация категории «Безопасность», законный результат с проверенными полномочиями | +2 |
| Явно частичный законный результат с проверенными полномочиями | +0,5 |
| Вредный исход ситуации | −2, при serious/critical −4 |
| Нейтральный, ничья или положительный без доказанных полномочий | 0 |

В каждом подтверждённом действии ограничение совокупной производной безопасности составляет ±4 п.п. Все значения ограничены 0–100%. Знаки меняются при противоположном изменении исходного фактора.

## Совместимость с действующей игрой

- Штрафы за первоначальное возникновение кризиса (−0,5/−1,5/−3/−6) уже существуют и не меняются. Новые эффекты начисляются за дальнейшие подтверждённые изменения угрозы и локализации и за законное завершение.
- Деловая активность, автоматически вычисляемая из безопасности, НЕ участвует в обратном начислении безопасности. Учитывается только явно заданный activity_override с числовыми значениями до/после. Значение null при первом задании не интерпретируется как реальная дельта.
- Происходящие через легитимность изменения социальной стабильности, напряжения и международного положения не влияют повторно на безопасность. Пропущены источники событийных правил голосований, кризисов и публикаций; при событиях категории «Безопасность» исключается повторное влияние косвенных изменений экономики и правовой устойчивости.
- Для событий категории «Безопасность» используется выбранный вариант effect_plan и его public_interest, а не суммарное изменение доверия. Положительный результат требует проверки lawful и уже существующих evidence с authority_ok и best_option. Используются существующие индексы event_decisions(case_id,actor_id) и event_authority_evidence(decision_id).
- Нефть и курс валюты не получают прямого коэффициента: существующие финансовые и экономические связи сохранены, без повторного учета.
- Исторические результаты, состав игровых органов, полномочия, RLS, правила, предыдущие начисления, министерства и государственные программы не менялись.

## Оптимизация

- Новых браузерных запросов, подписок, таймеров, заданий, таблиц и индексов: 0.
- На одно реальное изменение производится максимум одно обновление security и одна запись в уже существующую историю, без записей при нулевой или обрезанной дельте.
- Производные записи security не порождают отдельные автоматические новости, но доступны через имеющуюся историю. Оригинальные политические новости сохраняются.
- Продолжает действовать ранее добавленный ограничитель однократной дорогостоящей синхронизации бюджетного прогноза на игру и транзакцию.
- Функции работают только в private с отозванным правом EXECUTE для anon, authenticated и PUBLIC.
- При 100 одновременных игроках фактическое число дополнительных записей, WAL и Realtime сообщений пока не измерялось; нулевая внутренняя нагрузка не заявляется.

## Проверки на базе

Все сценарии выполнялись в транзакциях с ROLLBACK: независимые +0,7/+0,4/+0,3/+0,2; изменение инфляции −2, ставки −2, ручной активности +5 даёт совокупный эффект +4 после ограничения; кризис 45/55 → 25/75 даёт +3; повтор той же команды 0; закрытие кризиса +1; законный подтверждённый исход ситуации +2; положительный без полномочий 0; серьёзный вредный −4.

Отдельно регрессионно подтверждена действующая цепь экономика → доверие/элиты → легитимность → социальные показатели; её необходимо учитывать при тестировании абсолютных значений.
