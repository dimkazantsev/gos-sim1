# Связь целей и структуры государственной программы

Верхняя часть формы описывает результат программы и его измеримый показатель. Нижняя показывает проекты, целевые программы и мероприятия, которые обеспечивают этот результат, и их обоснованные расходы.

Для каждого элемента выбирается основная цель программы. Рядом отображаются её показатель, исходное/целевое значения и год. Под карточкой цели видны связанные элементы; переход раскрывает нужный элемент. Расходы добавляются внутри элемента после выбора цели и заполнения его вклада в результат.

Связь сохраняется как идентификатор цели, с проверкой принадлежности той же программе и игре. Повторное сохранение атомарно пересоздаёт строки и восстанавливает связи. Удаление используемой цели запрещено; сначала нужно переназначить элементы. Старые программы читаются без выдуманной автоматической связи.

Проверка: реальный SQL-сценарий с фиктивными данными и полным откатом прошёл сохранение, повторное сохранение, одинаковые названия показателей, недопустимые ссылки, защиту удаления, подпись/публикацию, защиту подписанного текста, точность расходов и каскад удаления всей игры. Браузерные проверки реального редактора с имитацией транспорта прошли девять сценариев и четыре ширины (320,390,768,1440), без ошибок выполнения.

Воспроизведение: `node scripts/program-goal-links-browser-check.cjs`; SQL в `scripts/program-component-goal-links-check.sql`.
