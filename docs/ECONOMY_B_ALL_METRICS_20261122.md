# ГОС.ID · Модель Б — влияние всех 10 показателей (22 ноября 2026)

Предыдущая [утверждённая модель Б](ECONOMY_B_APPROVED_20261120.md) сохраняет прямые коэффициенты для экономики, доверия граждан и правовой устойчивости. По новому поручению владельца семь остальных показателей подключены к тем же экономическим каналам.

**Важно:** индивидуальные коэффициенты новых семи показателей раньше не утверждались. Использованы ранее принятые чувствительности **0,002** (деловая активность) и **0,0005** (налоговая собираемость). Распределение этих чувствительностей по двум равновесным группам — **новое модельное допущение**.

| Показатель | Экономический канал | Знак |
| --- | --- | --- |
| Социальная стабильность | Деловая активность | + |
| Безопасность | Деловая активность | + |
| Поддержка элит | Деловая активность | + |
| Международное положение | Деловая активность | + |
| Социальное напряжение | Деловая активность | − |
| Легитимность | Собираемость налогов | + |
| Информационный фон | Собираемость налогов | + |

Сдвиг деловой активности: `clamp((Δстабильности + Δбезопасности + Δподдержки элит + Δмеждународного положения − Δсоциального напряжения) / 5 × 0.002, −0.03, +0.03)`.

Сдвиг собираемости: `clamp((Δлегитимности + Δинформационного фона) / 2 × 0.0005, −0.01, +0.01)`.

Каждый Δ измеряется относительно опорного значения **той же игры** в `budget_simulator_state.anchor.aux_metrics`. Изменение исходных показателей на момент включения равно нулю; история, баллы, решения, правовые статусы, ставки и суммы принятых документов не переписываются.

Федеральный расчёт: `private.calculate_budget_simulator` и `components/game/federalBudgetMath.ts`; региональный: `components/game/fiscalMath.ts`. Клиентский `get_fiscal_context` отдаёт опорные значения в существующем ответе, без нового запроса. Кэш подписи и отложенный серверный пересчёт теперь следят за всеми десятью показателями; нет новых таблиц, опросов, подписок и фоновых заданий.

Проверка: `node scripts/economy-b-all-metrics-check.cjs`, а также серверные транзакционные проверки с `ROLLBACK`. Нагрузка 100 одновременно активных игроков и полное прохождение этапов 12–16 не подтверждены.
