# Исправления форм и процедур по скриншотам 8 октября 2026

Источник требований: девять скриншотов и сообщение пользователя; исходные правила игры (сохранённая копия original-game-rules.txt). Изменения сохраняют действующие регистрацию, кворум, маршруты НПА и бюджетное утверждение.

| Проверка | Условие приёмки | Доказательство |
| --- | --- | --- |
| Список способов распределения | Полное название видно в поле и меню; стили проекта | Проверка браузером на широком и узком экранах |
| Президент, первый тур | Доли голосов ППС за программу и агитацию; доля игровых баллов; среднее 3/4 компонентов | Расчёт на фиксированных исходных данных, SQL и браузер |
| Президент, второй тур | (Зафиксированный результат первого тура + новое голосование ППС) / 2; без нормализации на финалистов | SQL для второго тура и равенства результатов |
| Госпрограмма | Паспорт, цели, структура и построчные обоснованные расходы доступны до первого сохранения; суммы и годы считает сервер | Сохранение и повторное чтение формы |
| Подпись программы | Только уполномоченный участник; одна публикация и один набор годовых обязательств | Проверки прав, повторного действия и транзакции |
| Бюджет | Подписанная программа видна с расходами в рублях; бюджетная процедура сохраняется | Повторное чтение и браузер |
| Второе чтение | Поправки только субъектов инициативы, цветное сравнение, выбор пакета, голосование, применение принятого текста | Проверки прав, кворума, устаревшего текста и перехода чтений |
| Муниципальное управление | Термины администрации, формы в стиле проекта, сохраняются Google-презентации | Проверки ссылки и сохранения формы |
| Кризисы | Преподаватель видит каталог из правил и дополнительные варианты; выбор и случайный запуск | Проверка каталога и сценария запуска |
| Шапки и рефлексия | Числа и надписи не пересекаются и не обрезаются | Проверка браузером на нескольких ширинах |
| Регрессии | Типы, сборка, существующие проверки и значимые новые сценарии проходят | npm run check и браузерные/SQL проверки |

Формула первого тура: доля программы = голоса за кандидата / все голоса ППС × 100; аналогично агитация. Игровой компонент = баллы кандидата / сумма баллов кандидатов × 100. Опрос включается по решению участников. Итог — среднее четырёх компонентов или трёх без опроса. Действующие штрафы ЦИК и партийный модификатор отражаются отдельно после среднего.

Абсолютная система требует строго больше 50% до округления; квалифицированная — установленный порог. При необходимости во второй тур проходят два лидера. Равенство на границе финалистов или среди возможных победителей не разрешается порядком записей. Для преференциальной системы требуются ранжированные бюллетени.

Госпрограмма после подтверждения проходит министра и Председателя Правительства. Подпись публикует программу и планируемые расходы; заседание Правительства и последующее принятие бюджетных ассигнований остаются самостоятельными процедурами.
