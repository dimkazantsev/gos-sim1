# Восстановление GOS//SIMS

## Основное Приложение

1. Распакуйте Архив Исходников И Перейдите В `gos-sim1`.
2. Установите Node.js 20.9 Или Новее И Выполните `npm ci`.
3. Скопируйте `.env.example` В `.env.local`; Укажите URL Своего Supabase И Его Публичный Publishable Key.
4. Для Уже Существующей Рабочей Базы Новые Миграции Этой Итерации Применены. Не Запускайте Их Повторно Вручную.
5. Для Новой Базы Примените `supabase/schema.sql`, Затем Файлы Из `supabase/migrations` По Порядку Версий. Проверьте Зависимости Расширений И Storage В Своём Supabase Окружении.
6. Выполните `npm run typecheck`, `npm run build`, Затем `npm run dev` Для Разработки Или `npm run start` Для Готовой Сборки.

Архив Данных Не Содержит Пароли Auth Или Секреты Подключения. Для Переноса В Другой Supabase Создайте Аккаунты И Сопоставьте Прежние User_id С Новыми Во Всех Связанных Записях. Восстановите Таблицы Из JSON С Учётом Внешних Ключей И Ограничений, Затем Загрузите Реальные Файлы В `game-assets` И `game-media` По Сохранённым Путям. Автоматический Импорт В Чистый Supabase В Этой Итерации Не Тестировался.

## Сеанс В Браузере Или Локальной Сети

Новый Интерфейс Профиля Предлагает JSON, HTML И ZIP. Для Полной Копии С Медиа Выберите ZIP И Убедитесь, Что Файл Сохранился. Удаление Сеанса Доступно После Экспорта ZIP, Подтверждения И Ввода Точного Кода Игры.

HTML Открывается Как Локальный Файл И Хранит Прогресс В Одном Браузере. В Этом Режиме Роли Свободно Переключаются Для Репетиции.

В Распакованном ZIP Запустите `node server.mjs`. Откройте `http://localhost:8080`; Другие Компьютеры Локальной Сети Используют Адрес Этого Компьютера И Порт 8080. Новые Коды Преподавателя И Участников Появятся В Терминале. Гость Входит Без Кода И Может Только Просматривать. Общий Прогресс Сохраняется В `progress.json`.

Проигрыватель Не Выполняет Все Процедуры Полной Платформы. Для Полных Выборов, Подписей, Институтов И Чатов Используйте Основное Приложение С Supabase.
