Область изменения: только видимое окно публикаций и стандартная кнопка раскрытия. Не меняются хранилище, существующая сортировка (закреплённые выше, далее новые), поиск, фильтры, публикация, вложения, обсуждения, голосования, НПА, роли и оценивание.

## Проверки автоматизации

- `scripts/political-wall-feed-check.cjs`: 0, 1, 9, 10, 11, 20, 25, 101 публикация; шаг +10; достижение последней; отсутствие потерь; сброс лимита; привязка к компоненту.
- GitHub Actions: `build-check.yml` + `teacher UI` + `budget verification` только после прохождения полного набора.
- Production: отдельно проверить Vercel status у merge-коммита; не считать успешный PR-build доказательством публикации.

## Дополнительная проверка: массовое удаление (преподаватель)

Выпуск: отдельный PR на основе успешно опубликованного PR №55. Проверка проводится **без реального удаления производственных записей**; для проверки самой операции использовать тестовую публикацию либо тестовую игру.

| Сценарий | Условие | Контрольный вопрос | Корректировка |
|---|---|---|---|
| Права | Режим массового удаления и флажки доступны только преподавателю; участник и гость не видят кнопки; серверная RPC повторно проверяет права | Участник и гость действительно не могут выполнить групповое удаление? | _Ваши замечания:_ |
| Выбор | Отметка по одному, «Выбрать показанные», «Снять всё», выбор сохраняется при показе следующих 10 и фильтрации | Удобно ли выбирать посты с разных страниц ленты? | _Ваши замечания:_ |
| Защита | Перед удалением обязательно подтверждение с количеством и названиями нескольких постов; отмена ничего не меняет | Достаточно ли понятен состав удаляемых публикаций? | _Ваши замечания:_ |
| Результат | Используется действующая `delete_process_post`; ограничены параллельные вызовы; одна финальная синхронизация; неудалённые записи сохраняют выделение | Корректно ли обновляется лента после удаления? | _Ваши замечания:_ |

| Адаптивность | Кнопка и флажки доступны на смартфоне без горизонтального переполнения | Комфортен ли выбор с экрана телефона? | _Ваши замечания:_ |

**Принятый компромисс:** «Выбрать показанные» отмечает только раскрытые в данный момент карточки, а не все скрытые публикации. Для массового удаления большого диапазона преподаватель может последовательно раскрыть следующие десятки и отметить их. Это предотвращает случайный выбор сотен невидимых постов.
