# Публикация Игры На GitHub Pages

Основной сайт: https://gos-sim1.vercel.app/.

GitHub Pages пока не включён. Подготовленная сборка использует ту же базу Supabase и те же серверные права, что основной сайт. Прогресс игр не копируется и не обнуляется. На новом адресе потребуется войти в свою учётную запись заново.

## Существующий Закрытый Репозиторий

Если тариф GitHub поддерживает Pages для закрытых репозиториев:

1. В настройках `dimkazantsev/gos-sim1` откройте Pages.
2. Выберите GitHub Actions в поле Source.
3. Во вкладке Actions запустите workflow `Public game on GitHub Pages` для Main.
4. После успешной публикации используйте адрес, показанный в Pages или в задании Deploy. До этого публичного адреса GitHub Pages нет.

## Бесплатный Публичный Репозиторий

На бесплатном тарифе Pages требует публичного репозитория. Сохраните существующий репозиторий закрытым и создайте отдельный публичный репозиторий `gos-sims-public` только для готовой браузерной сборки.

1. Используйте архив `GOS-SIMS-GitHub-Pages-public-2026-09-30.zip`. Он собран для пути `/gos-sims-public`.
2. Распакуйте архив и загрузите содержимое папки `Site` в корень нового репозитория. Сохраните файл `.nojekyll`.
3. В Pages выберите Deploy From A Branch, Main, Root и сохраните настройку.
4. Используйте фактический адрес, появившийся в Pages после успешного развёртывания.

Архив содержит только файлы браузерной версии. Фотографии участников, документы, пароли и сохранённые сеансы в него не включены. Серверная проверка прав продолжает выполняться в Supabase.

## Повторная Сборка

Для существующего репозитория:

```bash
node scripts/prepare-github-pages.mjs
cd .pages-build
npm ci
npm run build
cd ..
node scripts/github-pages-check.mjs
```

Для отдельного публичного репозитория перед подготовкой и проверкой установите `PAGES_BASE_PATH=/gos-sims-public`. Подготовка адаптирует вход в игру к статическому адресу с параметром `Game`, пути к иллюстрациям и экспортам, а также восстановление пароля. Обработку TXT выполняет браузер; PDF/DOCX прикрепляются с ручным вводом текста, как на основном сайте.

Добавьте фактический адрес страницы `/auth/update-password/` нового сайта в разрешённые Redirect URLs проекта Supabase. Пока это не настроено, для восстановления пароля используйте основной сайт.

Сборка и проверка путей не заменяют проверку входа на опубликованном адресе. После включения Pages проверьте вход существующим пользователем, обновление игры, голосование и получение изменения на другом устройстве.
