# ГОС.ID — зависимость легитимности от доверия и элит; экономические каналы

Дата: 23.11.2026. Внедрение относится **только к новым изменениям показателей**, не пересчитывает историю, оценки, протоколы и принятые НПА. Источники: `state_metrics`, `state_metric_history`, `impact_rules`, `fiscal_change_ledger`; код и функции действующей модели Б.

## Утверждённая пользователем связь легитимности

`ΔL = clamp(0.18 × Δpublic_trust + 0.12 × Δelite_support, -1, +1)`.

Это 60% доверия, 40% элит с общим коэффициентом 0,3. Для двух изменений одного первичного действия суммарная производная корректировка ограничена ±1 п.п.; показатели всех трёх осей ограничены 0–100. Ручная правка преподавателем по-прежнему разрешена и учитывается как самостоятельное действие.

У уже работающего `vote_passed` прямой эффект легитимности меняется на **+0,35**, а производный эффект +0,5 доверия и +0,5 элит даёт +0,15. Поэтому **суммарный результат прежнего успешного голосования остаётся +0,5**. Для прошлых голосований исторические значения не изменяются.

## Новые экономические влияния (консервативные модельные допущения)

| Изменение драйвера | Δ доверия, п.п. | Δ элит, п.п. |
|---|---:|---:|
| Инфляция +1 п.п. | −0,10 | −0,05 |
| Ключевая ставка +1 п.п. | −0,05 | −0,05 |
| Деловая активность +1 п.п. | +0,08 | +0,10 |
| Цена нефти +1 доллар за баррель | 0 | +0,02 |

Падение/снижение параметров обращает знак эффекта. Лимит **±0,5 п.п. на доверие и ±0,5 п.п. на элиты за одно изменение макроэкономических параметров**. Эти числовые коэффициенты выбраны как консервативные технические значения и могут быть изменены при отдельной калибровке; это **не** эмпирически оценённые коэффициенты причинного влияния.

Реализация использует только *фактическую разницу* `before_values/after_values` из уже существующего финансового журнала. Деловая активность берётся из непосредственной разницы `activity_override` при её изменении. Изменение `economy` учитывает лишь уже утверждённый канал `0.002` коэффициента активности (= 0,2 п.п. деловой активности на 1 пункт экономики, до масштабирования ручным уровнем), не вычисляя производное изменение от доверия или элит; иначе возник бы цикл.

## Нагрузка

- **0 новых запросов/RPC от браузера, 0 подписок, 0 таймеров, 0 фоновых заданий, 0 новых таблиц.**
- Использован **существующий** триггер финансового журнала: `private.fiscal_ledger_metrics_trigger` теперь не делает ненужный выбор `fiscal_change_ledger` для источников, отличных от `event`/`act`.
- Один макроэкономический источник обновляет только реально изменившиеся доверие/элитную поддержку и **одну** легитимность. Максимум 3 изменения показателей и 3 записи истории, а не 4 из наивного последовательного расчёта. Одно изменение экономики использует максимум 4 записи истории (включая собственную), без дополнительного чтения экономической политики.
- Уже работающие голосования получают **одно** производное обновление легитимности вместо двух, без повторной реализации эффектов.
- Нулевые изменения проходят без записи истории. Границы 0–100, существующие ключи изоляции `game_id` и права доступа сохранены.
- **Новые записи для действительно изменившихся показателей неизбежны.** Они также вызывают существующие уведомления Realtime. Это не нулевая внутренняя стоимость, и отсутствие деградации на 100 реальных участниках должно подтверждаться отдельным нагрузочным измерением.

## Контроль

Реальные сценарии с завершающим `ROLLBACK`: +2 доверия/+2 элит → +0,6 легитимности; макро `ставка +1, инфляция +1, активность +2, нефть +10` → доверие +0,01, элиты +0,30, легитимность +0,0378 и ровно три записи истории; экономика +5 → доверие +0,08, элиты +0,10, легитимность +0,0264 и ровно четыре записи истории; голосование по прежнему +0,50 легитимности; повторная макрозапись без изменения параметров не создаёт истории; суммарная связь с одним источником ограничена ±1.

Не изменяются уже заданные значения игровой легитимности, доверия, элит, инфляции, нефти, ключевой ставки, экономики, ФНБ и бюджета во время миграции.
