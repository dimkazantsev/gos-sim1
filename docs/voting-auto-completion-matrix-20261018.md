# ГОС.ID: Контроль автоматического завершения голосований

Дата проверки: 18.10.2026. Основания: инструкция проекта «ГОС ID.md» (снимок 12.10.2026), фактические функции/триггеры работающей Supabase и main GitHub после PR №253. Приведены технические правила *симуляции*; независимая правовая экспертиза федерального и регионального законодательства в рамках этой проверки не проводилась.

## Единое условие

Автоматическое завершение допустимо, когда (а) достоверно определён состав имеющих право голоса в данной процедуре; (б) каждый такой *зарегистрированный* участник уже подал голос; (в) достигнут предусмотренный именно этой процедурой кворум. Проверять реального участника и мандаты на сервере. Подсчёт победителя, тайна волеизъявления, вторые туры и все утверждённые пороги остаются прежними. Последний голос и закрытие — единая транзакция с блокировкой строки голосования; повторное закрытие не создаёт второго результата.

## Матрица подсистем

| Процедура / таблица | Реализация / причина исключения |
|---|---|
| Стандартные процедуры (ГД, СФ, Правительство, КСРФ и другие органы), `game_votes` + `game_ballots` | **Уже действует** `private.close_vote_after_last_registered_ballot`: требуется снимок электората, регистрация и кворум голосования; КСРФ использует один голос фракции, ГД — вес мандатов. Изменения в логике не требуются. |
| Выборы председателя и заместителей ГД, председателей комитетов, персональные мандатные бюллетени | **Уже действует** после PR №253: `cast_personal_office_ballot` → `private.auto_finish_personal_office_election_locked`, кворум не менее 226. Второй тур — прежний расчёт. |
| Выборы должностей фракционными пакетами (`office_ballots`) | **Новое:** зарегистрированные руководители официальных фракций с положительным числом мандатов должны полностью распределить свои пакеты, суммарно не менее 226 мандатов. Неполный пакет ещё можно распределить между кандидатами; автозавершение до этого момента недопустимо. Используется существующий `private.finish_office_election_locked`. |
| Выборы председателя партии (`party_chair_ballots`) | **Уже действует:** при голосовании всех действующих членов партии итог определяется автоматически в `vote_for_party_chair`; ничья не подменяется победителем. Депутатский мандат здесь не требуется. |
| Выборы главы муниципалитета (`municipal_mayor_ballots`) | **Новое:** автозавершение при голосовании 100% действующих участников игры, которым предоставлен один муниципальный голос. В существующей функции отдельный параметр кворума отсутствует, поэтому меньший порог не вводится. Обычный подсчёт, ничья и назначение должности сохраняются. |
| Законопроектные поправки: `bill_amendments` | **Сохранён специальный порядок:** отдельная защищённая функция `close_bill_amendment_vote`, блокировки текстов, допуск председателя ГД или профильного комитета, различие ФКЗ и ФЗ. Общий триггер умышленно исключает эти процедуры. Не обходить проверку редакций документов автоматическим изменением `game_votes.status`. |
| Федеральный бюджет (внесение, чтения, вето, бюджетные поправки) | **Сохранён специальный порядок:** функции бюджетного расчёта, блокировки документа и процедур, отдельные правила двух третей и 226 из 450. Автозавершение штатным общим триггером отключено до отдельного согласованного безопасного переноса защищённых финализаторов; простой вызов от имени голосующего не даёт нужных полномочий. |
| Решение об использовании опросов на президентских выборах (`presidential_poll_decision_votes`) | **Не мандатное голосование:** отдельный опрос студентов без снимка мандатного электората и прописанного кворума. Решение и закрытие остаются по прежней процедуре. |
| Публичный президентский соцопрос (`presidential_public_poll_votes`) | **Без фиксированного числа избирателей:** анонимные токены и срок публикации, невозможно достоверно установить, что проголосовали «все». Закрытие сохраняется по времени/установленному порядку. |
| Голосование преподавательского жюри на президентских выборах (`presidential_teacher_ballots`, `presidential_teacher_jury_votes`) | **Специальные 8 слотов и критерии:** оценивание преподавателей, а не депутаты с мандатами. Нельзя подменить 3/8, 8/8 и другие особые условия общим депутатским кворумом. |
| Вопросы `org_quiz_votes`, `org_quiz_duel_votes` | **Отдельная интеллектуальная игра:** не относится к голосованиям органов публичной власти ГОС.ID; не менять её режимы без отдельной задачи. |

## Непосредственные зависимости

- `game_votes` → `game_ballots` → триггеры фиксации результата, НПА, бюджет, публикации/уведомления;
- `office_elections` → `office_personal_ballots` / `office_ballots` → `trg_committee_chair_election` / назначение должностей;
- `municipal_mayor_elections` → `municipal_mayor_ballots` → изменение `game_members.role_title`;
- `party_chair_ballots` → `game_parties.leader_user_id`.

Тестировать: отказ без прав и регистрации; недостаток кворума; 1/2, 39/40 и 40/40; разнонаправленные голоса; отсутствие двойного закрытия; сохранение существующих отдельных формул; не переносить результат на соседнее голосование.

**Граница этой поставки:** бюджетные и законопроектные процессы не переведены на общий финализатор, так как это требует переноса отдельных серверных защит и согласования допустимого момента фиксации документа. Этот пункт не считается завершённым и не должен обозначаться как внедрённый.
