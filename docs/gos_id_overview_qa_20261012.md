# ГОС.ID — проверка публикации брендирования и актуальности обзора

Проверено в исходном коде: два SVG-варианта, вход, боковая панель, мобильная шапка, экран для аудитории, эмблема постов, достижения, Telegram, опрос, экспорт и пролог. Название **ГОС.ID — Цифровая платформа Российской Федерации**; `//` сохранено как декоративный разделитель, не как старое имя. Внутренние ключи пользовательских настроек оставлены без изменения.

**Причина старых записей на скриншоте:** старый блок «Что происходит» использовал `game_events`, а «Политический процесс» использует `political_posts`. Это разные таблицы. В момент диагностики в рабочей базе было 13 записей в `game_events` и 0 активных публикаций в `political_posts` (43 удалены). Теперь обзор запрашивает только 4 активных поста по тому же порядку (закреплённые, затем новые), с обновлением при возвращении к вкладке и каждые 30 секунд пока она видна. Историческая таблица не очищается.
