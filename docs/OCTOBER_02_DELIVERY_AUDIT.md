## Независимые проверки

Серверные тесты работают от роли authenticated, с временными участниками и полной транзакционной отменой. Реальные профили, переписка, голоса и оценки не создаются и не удаляются при проверке.

- fiscal-integration-check.sql: 19 проверок.
- achievement-integration-check.sql: 11 проверок.
- deadline-integration-check.sql: 11 проверок.
- classroom-links-integration-check.sql: 11 проверок.
- registration-media-integration-check.sql: 8 проверок.
- fiscal-plans-integration-check.sql: 8 проверок.
- Итого: 68 серверных утверждений.
- Полная CI-проверка включает TypeScript, дизайн, вход/обновление, карточки событий, правовой портал, политический процесс, бюджет/награды/этапы/чат, интерактивность, навигацию, мобильные и преподавательские экраны, журнал влияния и production build.
- Новые механизмы проверяются при ширине 320, 390, 768 и 1440 пикселей. Дополнительно просмотрены сохранённые снимки карты, стенда наград и комикса.

## Данные и границы модели

Реальная региональная статистика — официальный отчёт ФНС 1-НМ за 2025 год: пять сопоставимых показателей для 85 регионов. Для четырёх отсутствующих наблюдений оставлены null, а не вымышленные значения. Источник, год и единицы видны отдельно от учебных расчётов. См. REGIONAL_STATISTICS_METHOD.md.

Карта содержит 89 записей российского административного перечня. Спорные территории отмечены штриховкой; справочная геометрия 2017 года не обозначает фактическую линию контроля. Лицензия и источник указаны в интерфейсе.

Сокращённые нормативы зачисления налогов и реакция деловой активности являются учебными допущениями, а не точной моделью всех бюджетов РФ. Платежи без заданной специальной базы не включаются в арифметическую сумму доходов. Структурированный федеральный сценарий хранит собственный источник единиц; его суммы не смешиваются с миллионами регионального прогноза.

Автоматическое изменение ставок связано с конкретным предложением и допустимым опубликованным актом. Свободный текст произвольного НПА сам по себе не считается доказательством изменения ставки. Утверждение программы не считается фактическим расходованием средств.

Все 150 новых задач написаны для игры по методике юридических учебных задач. Они не выдаются за скопированные университетские задания или состоявшиеся судебные дела. Диагностика текстового сходства помогает найти повторы, но не заменяет внешнюю юридическую экспертизу. См. CASE_CONTENT_AUDIT.md.

Рабочая основа этапов — существующие 16 этапов и правила проекта, выбранные пользователем. Недоступный внешний документ не был заменён вымышленной редакцией правил. Размеры дисциплинарных последствий задаёт преподаватель; расчёт не устанавливает новые обязательные штрафы от своего имени.

## Публикация

Vercel остаётся действующим публичным адресом приложения. Подготовлена проверяемая статическая сборка для https://dimkazantsev.github.io/gos-sim1/ с тем же Supabase и авторизованным API извлечения документов.

GitHub Pages не включён владельцем репозитория. Автоматическое создание сайта получило Resource not accessible by integration. Код сборки и workflow подготовлены; для завершения этого внешнего шага владельцу нужны Settings → Pages → Source: GitHub Actions. Репозиторий не переводился из приватного в публичный.
